## Pasting into Confluence

1. Create the page and type the title.
2. Open **Insert → Markup** (Ctrl+Shift+D), choose **Markdown**.
3. Paste the file's contents (without the first `# ` title line if you already typed the title) and insert.
4. Optional: turn lines starting with **Note:** / **Important:** into Info / Warning panels.
